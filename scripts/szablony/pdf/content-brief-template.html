Content brief template: a 10-part SEO brief

One brief = one piece = one URL. The client fills in parts 1–5 before talking to the writer, parts 6–9 you complete together, and part 10 is for reviewing the draft. Version: November 2026.

How to use this template

  1. Pick the keyword and the URL: check Search Console (Performance → filter by query → Pages tab) to see whether another page of yours already shows up for that keyword.
  2. Review Google’s results in a private window: the top five, the AI Overview and related questions. Record them in part 4.
  3. Add what the piece will contribute (part 5) and build the outline (part 6). Approve the outline before writing starts.
  4. Review the draft with the checklist (part 10): write comments next to the check number.
