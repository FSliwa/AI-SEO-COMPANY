How to use this template

  1. Record your baseline (part 1): a crawler, your XML sitemap, the Links report in Search Console.
  2. Pick your priority pages (part 2) and give each a priority from 1 to 3.
  3. Assign their anchors in the register (part 3).
  4. Draw the hub-and-spoke map (part 4): each hub and its spoke pages.
  5. Write the link plan (part 5), starting with priority 1 pages.
  6. Every quarter, run the audit (part 6) and decide on orphan pages (part 7).
  7. Measure the effect (part 8) in Search Console.

The rules in brief

  • The hub links to every spoke, and every spoke links back to the hub.
  • New content: a link to the hub and to 2–4 pages in the same cluster; the hub links to it on the day it goes live.
  • Priority 1 pages get the most incoming internal links.
  • Important pages sit no more than 3 clicks from the homepage.
  • Anchor text is descriptive and concise; one anchor = one target page.
  • Link to the canonical, final URL with no redirects; use an <a href> element, no nofollow.

7. Orphan pages and decisions

Link it: an important page, or one with impressions (positions 4–20). Merge: several weak pages on one topic (301). Remove: no traffic, links or value (410, or 301 to the parent page). Noindex: a page people need but search results don’t. Update the sitemap after each decision.
